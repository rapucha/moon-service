# Stack

- Java 25 and a Maven reactor with root artifact `moon-service`.
- `backend/`: Spring Boot Web, JDBC, Flyway/PostgreSQL, and Caffeine. Tests use Spring Boot Test, WebTestClient, and Testcontainers PostgreSQL.
- `prototypes/jvm-scoring/`: Maven scoring and ephemeris module using Astronomy Engine, Jackson, and JUnit Jupiter.
- `frontend/`: browser JavaScript and static assets served by the backend.
- `scripts/`: Python development, validation, and asset-authoring utilities.
